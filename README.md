# Business OS – klikací prototyp

Klikací prototyp podnikatelského ekosystému pro MSE v aplikaci Moje RB (Podnikatelská zóna):
terminál v telefonu, úvěr z tržeb, obálky, daně a cash flow, tarif za aktivitu, asistent inkasa,
firemní karty, napojení na účetnictví, založení firmy a odvětvové balíčky.

Všechna data jsou ukázková. Zdrojový kód a build jsou v repozitáři `anorfidien/rb-podnikatelska-zona` (složka `proto/`).
